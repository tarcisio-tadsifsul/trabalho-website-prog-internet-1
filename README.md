# 🍳 Website de Receitas

Projeto desenvolvido para a disciplina de **Programação para Internet I**, com foco na criação de um website responsivo utilizando **HTML5** e **CSS3**.

---

## Sobre o Projeto

O projeto consiste em um website de receitas culinárias, contendo páginas informativas, catálogo de receitas e formulário de envio de conteúdo pelos usuários.

O objetivo principal é aplicar conceitos fundamentais de desenvolvimento web, como:

- HTML semântico
- CSS Grid
- CSS Flexbox
- Responsividade
- Navegação entre páginas
- Estruturação de conteúdo
- Componentes obrigatórios da disciplina

---

## Objetivos

- Desenvolver um website funcional e responsivo
- Aplicar boas práticas de HTML e CSS
- Criar uma navegação intuitiva
- Utilizar layouts modernos com Grid e Flexbox
- Organizar o projeto seguindo uma estrutura semântica

---

## Funcionalidades

- ✅ Menu de navegação sticky
- ✅ Layout responsivo
- ✅ Catálogo de receitas
- ✅ Página interna de receita
- ✅ Formulário de envio de receitas
- ✅ Tabela de informações nutricionais
- ✅ Menu mobile (hambúrguer)
- ✅ Estrutura semântica HTML5

---

## Estrutura de Páginas

### Home

Página inicial com:

- Destaques da semana
- Categorias populares
- Barra de busca
- Receitas em destaque

### Receitas

Página de listagem contendo:

- Catálogo completo de receitas
- Cards de receitas
- Categorias

### Receita (Página Interna)

Página detalhada da receita contendo:

- Foto do prato
- Ingredientes
- Passo a passo
- Vídeo de preparo
- Áudio descrição
- Tabela nutricional
- Conversão de medidas

### Sobre

Página com:

- Informações do autor
- Objetivos do projeto
- Apresentação pessoal

### Contato / Envie sua Receita

Página contendo formulário com:

- Nome da receita
- Upload de imagem
- Tempo de preparo
- Categoria
- Modo de preparo
- Campo de contato
